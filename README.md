# 植物大战僵尸 Web 游戏


## How to Run

### 方式一：使用 Docker（推荐）

```bash
# 构建并启动服务
docker-compose up --build -d

# 访问游戏
# 打开浏览器访问: http://localhost:8081
```

停止服务：
```bash
docker-compose down
```

### 方式二：本地运行

#### 前置要求
- Node.js 18+ 
- npm 或 yarn

#### 运行步骤

```bash
# 1. 进入前端目录
cd frontend-user

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev

# 4. 访问游戏
# 打开浏览器访问: http://localhost:8081
```

#### 构建生产版本

```bash
# 在 frontend-user 目录下执行
npm run build

# 构建产物将生成在 dist 目录
```

## 项目介绍

这是一个基于 Vue 3 + Vite + Element Plus 构建的植物大战僵尸网页游戏。游戏还原了经典的塔防玩法，玩家需要种植各种植物来抵御僵尸的入侵。

### 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Vite** - 下一代前端构建工具
- **Element Plus** - Vue 3 组件库
- **Pinia** - Vue 状态管理
- **SCSS** - CSS 预处理器
- **Axios** - HTTP 客户端
- **Docker** - 容器化部署

### 游戏特性

- 🌻 **6种植物**：向日葵、豌豆射手、坚果墙、寒冰射手、双发射手、樱桃炸弹
- 🧟 **3种僵尸**：普通僵尸、路障僵尸、铁桶僵尸
- 🎮 **经典玩法**：收集阳光、种植植物、抵御僵尸
- 🎨 **精美界面**：卡片式设计、流畅动画、爆炸特效
- 📱 **响应式布局**：适配不同屏幕尺寸
- ⏸️ **暂停功能**：ESC键暂停/继续游戏
- 🏆 **10波挑战**：难度递增的僵尸波次

### 游戏玩法

#### 基本规则
- **目标**：抵御 10 波僵尸进攻，保护你的房子
- **失败条件**：任何僵尸到达房子（最左侧）
- **胜利条件**：成功击退所有 10 波僵尸

#### 操作指南
1. **收集阳光**：点击天空掉落的阳光或向日葵产生的阳光
2. **选择植物**：点击顶部植物卡片（需要足够的阳光）
3. **种植植物**：选中植物后点击草坪格子进行种植
4. **取消选择**：右键或再次点击已选中的植物卡片
5. **暂停游戏**：按 ESC 键或点击暂停按钮
6. **重新开始**：点击顶部的重新开始按钮

#### 植物介绍

| 植物 | 阳光消耗 | 生命值 | 特性 |
|------|---------|--------|------|
| 🌻 向日葵 | 50 | 100 | 每12秒产生50阳光 |
| 🌱 豌豆射手 | 100 | 100 | 发射豌豆攻击僵尸（伤害20） |
| 🥜 坚果墙 | 50 | 400 | 高血量防御植物 |
| ❄️ 寒冰射手 | 175 | 100 | 发射冰豌豆，减速僵尸（伤害20） |
| 🌿 双发射手 | 200 | 100 | 同时发射两颗豌豆（伤害20×2） |
| 🍒 樱桃炸弹 | 150 | 100 | 种植后立即爆炸，范围伤害（伤害1800） |

#### 僵尸类型

| 僵尸 | 生命值 | 速度 | 攻击力 | 特点 |
|------|--------|------|--------|------|
| 🧟 普通僵尸 | 100 | 0.4 | 10 | 基础僵尸 |
| 🧟‍♂️🔶 路障僵尸 | 200 | 0.4 | 10 | 戴路障，血量更高 |
| 🧟‍♂️🪣 铁桶僵尸 | 400 | 0.35 | 10 | 戴铁桶，血量最高 |

#### 游戏策略
- **前期**：优先种植向日葵积累阳光
- **中期**：在前排种植豌豆射手，后排继续种向日葵
- **后期**：使用坚果墙保护射手，用寒冰射手减速强力僵尸
- **紧急情况**：使用樱桃炸弹清理大量僵尸

### 开发说明

#### 代码规范
- 组件命名：PascalCase（如 `GameBoard.vue`）
- 文件组织：按功能模块划分目录
- 状态管理：使用 Pinia 集中管理游戏状态
- 样式管理：SCSS 变量统一管理主题色

#### 性能优化
- 使用 `requestAnimationFrame` 优化游戏循环
- 组件懒加载减少初始加载时间
- 生产构建启用代码压缩和 Tree Shaking
- Docker 多阶段构建减小镜像体积
